# Ellipse Motion Simulator

Animate a ball along an elliptical path with adjustable speed, pause/resume controls, and live position updates.

**Course:** CPSC 223N, CSU Fullerton — Spring 2026.

## Run with Mono

Requires Mono (`mcs`, `mono`) and Windows Forms support. Run from this directory in a desktop session:

```bash
bash run.sh
```

## Files

- `Ellispe-main.cs` — application source
- `Ellispe-ui.cs` — application source
- `run.sh` — original Mono build/run script
