# Ninety-Degree Motion

Animate a ball along a path with a ninety-degree turn, user-selected speed, and start/pause controls.

**Course:** CPSC 223N, CSU Fullerton — Spring 2026.

## Run with Mono

Requires Mono (`mcs`, `mono`) and Windows Forms support. Run from this directory in a desktop session:

```bash
bash r.sh
```

## Files

- `ninety-degree-main.cs` — application source
- `ninety-degree-ui.cs` — application source
- `r.sh` — original Mono build/run script
