# Imperial to Metric Converter

Convert inches to meters with a Windows Forms interface, input feedback, and Compute/Clear controls.

**Course:** CPSC 223N, CSU Fullerton — Spring 2026.

## Run with Mono

Requires Mono (`mcs`, `mono`) and Windows Forms support. Run from this directory in a desktop session:

```bash
bash build.sh
```

## Files

- `build.sh` — original Mono build/run script
- `ImpToMetConlogic.cs` — application source
- `ImpToMetConmain.cs` — application source
- `ITMCuserinterface.cs` — application source
