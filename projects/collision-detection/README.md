# Collision Detection

Simulate two moving balls with configurable speed and direction, live coordinates and distance, collision detection, and replay controls.

**Course:** CPSC 223N, CSU Fullerton — Spring 2026.

## Run with Mono

Requires Mono (`mcs`, `mono`) and Windows Forms support. Run from this directory in a desktop session:

```bash
bash run.sh
```

## Files

- `Ricochet2-main.cs` — application source
- `Ricochet2-ui.cs` — application source
- `run.sh` — original Mono build/run script
