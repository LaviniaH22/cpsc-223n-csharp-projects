# Ricochet Simulator

Explore ball motion with configurable initial position, direction, speed, and live speed adjustment.

**Course:** CPSC 223N, CSU Fullerton — Spring 2026.

## Run with Mono

Requires Mono (`mcs`, `mono`) and Windows Forms support. Run from this directory in a desktop session:

```bash
bash run.sh
```

## Files

- `Ricochet-main.cs` — application source
- `Ricochet-ui.cs` — application source
- `run.sh` — original Mono build/run script
